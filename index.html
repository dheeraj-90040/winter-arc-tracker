Golden Rules & Progression

Rule 1 — No ego lifting

The question every set is "can I control this weight perfectly?" — not "how much can I lift?" If the last 3 reps look ugly, the weight is too heavy.

Rule 2 — RIR (Reps In Reserve)

If you finish a set thinking "I could've done 3 more good reps," that's ~3 RIR.

Phase Target
All weeks 3 × 12 · rest 60–90s

Leave 1–2 good reps in the tank. Never train to failure this month.

Double progression (how you add weight)

For a "3 x 12" exercise: once you hit 12 reps on every set with 1–2 reps still in the tank, add a little weight next session — even if reps temporarily drop back down (e.g. 10kg→12.5kg might give you 9/8/8 again). That's normal. Build back up to 12/12/12, then increase again.

Avoid this month

Running sprints, box jumps, burpees, high-volume jumping, heavy barbell squats/deadlifts, max lifts, training to failure, ego lifting. None of these are necessary for Month 1.

Pain rule

Normal: muscle fatigue, burning, mild soreness.
Stop immediately for: sharp/pinching/joint pain, sudden pain, pain that changes your movement, dizziness, chest pain, unusual shortness of breath.
